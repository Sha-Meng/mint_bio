# 账号凭据安全交接模板

> 本文只记录凭据交接方式和清单模板。**禁止在仓库中填写真实密码、Token、私钥或验证码**。

## 1. 安全原则

1. 真实凭据不得提交到 Git 仓库。
2. 真实凭据应放在公司认可的密码管理器、加密文件或线下安全交接渠道。
3. 交接文档只记录：账号类型、用途、权限范围、保管位置、保管人、轮换规则。
4. 人员离职、外包结束、权限变更后必须回收或轮换凭据。
5. Directus Token、数据库密码、SSH 私钥、阿里云 AccessKey 都按高敏感凭据处理。

## 3. 服务器 SSH

建议记录但不填写真实值：

- 云厂商账号归属。
- ECS 实例名称。
- 登录方式：密码 / SSH key / 堡垒机。
- 登录用户类型：root / deploy / readonly。
- 是否允许公网 SSH。
- 安全组白名单。
- 私钥保管位置。

交接检查：

- 确认不再需要的 SSH key 已删除。
- 确认离职人员无登录权限。
- 确认安全组和登录审计开启。

## 4. 宝塔面板

建议记录：

- 面板入口。
- 账号类型。
- 绑定手机号 / 邮箱归属。
- 是否启用二次验证。
- 面板 SSL 状态。
- 哪些人员有管理员权限。

交接检查：

- 修改默认弱密码。
- 回收无关管理员。
- 开启二次验证。
- 确认面板入口不公开传播。

## 5. Directus 账号

### Admin

用途：

- 管理集合和字段。
- 管理角色权限。
- 处理 schema 级别变更。
- 处理系统配置。

限制：

- 不作为日常运营账号。
- 不随意生成长期 Static Token。

### Editor

用途：

- 新增 / 编辑 / 发布新闻。
- 上传新闻图片。
- 查看必要内容。

限制：

- 不应拥有 schema 修改权限。
- 不应拥有高危系统配置权限。
- Raw HTML 权限应谨慎控制。

## 6. MySQL 凭据

建议记录：

- 数据库名称。
- 用户名。
- 权限范围。
- 备份位置。
- 备份频率。
- 恢复演练记录。

禁止：

- 在文档中写真实密码。
- 多系统混用同一个高权限数据库账号。
- 把数据库 root 密码发给无关人员。

## 7. 阿里云 / DNS / CDN

建议记录：

- 主账号负责人。
- RAM 子账号列表。
- DNS 管理域名。
- CDN 加速域名。
- SSL 证书来源和到期时间。
- 缓存刷新权限归属。

交接检查：

- RAM 权限最小化。
- 离职人员 AccessKey 删除。
- CDN/DNS 高危操作有二次确认。
- 证书到期前有提醒。

## 8. Token / AccessKey / 私钥处理规则

- 生成后只在安全渠道保存。
- 不截图发到群里。
- 不写入 Markdown、代码、README、issue、聊天记录。
- 不写入 `.env` 并提交 Git。
- 临时 Token 用完及时删除或轮换。
- 怀疑泄露时立即轮换，并检查访问日志。

## 9. 交接流程

1. 梳理当前所有账号和权限。
2. 确认每个凭据的业务用途。
3. 删除无关人员权限。
4. 将真实凭据迁移到安全保管位置。
5. 用本模板记录凭据索引和负责人。
6. 由接手人验证登录和必要操作。
7. 记录交接完成时间。
8. 设置轮换提醒。

## 10. 权限回收流程

触发场景：

- 人员离职。
- 外包结束。
- 设备丢失。
- 凭据疑似泄露。
- 项目负责人变更。

操作：

1. 禁用或删除相关账号。
2. 轮换共享密码。
3. 删除 SSH key / AccessKey / Static Token。
4. 检查最近登录和操作日志。
5. 更新本交接模板。

## 11. 禁止事项

- 禁止在本文件中填写真实密码。
- 禁止把服务器 root 密码发给运营。
- 禁止多人共用 Admin 账号做日常运营。
- 禁止长期保留无人负责的 Token。
- 禁止把 `.env`、私钥、数据库备份上传到公开仓库。
