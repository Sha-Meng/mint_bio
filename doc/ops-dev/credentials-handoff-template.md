# 账号凭据查询说明

> 本文只说明“哪些凭据需要查询、在哪里查询、联系谁查询”。真实账号、密码、Token、Secret、私钥不写入仓库文档。

## 1. 查询方式

- 统一联系项目开发负责人获取真实凭据。
- 开发负责人可将本机临时凭据整理在 `doc/private/credentials.local.md`；该目录已加入 `.gitignore`，不得提交。
- 如公司已有密码管理器或加密文档，应优先以公司安全渠道为准。

## 2. 凭据清单

| 类型 | 用途 | 查询位置 |
|---|---|---|
| 阿里云主账号 | ECS、域名、DNS、CDN、证书等控制台操作 | 联系开发负责人，在本地私密凭据文档或公司安全渠道查询。 |
| 服务器 SSH | 登录 ECS / 源站排障和部署 | 联系开发负责人查询。 |
| 宝塔面板 | 管理站点、Nginx、SSL、MySQL、反向代理 | 联系开发负责人查询。当前确认：未开启二次验证，未绑定手机号 / 邮箱归属。 |
| MySQL root | 数据库最高权限维护 | 联系开发负责人查询；仅应急或维护使用。 |
| 官网网站数据库账号 | 官网业务数据库访问 | 联系开发负责人查询。 |
| Directus Admin | 管理集合、字段、权限和系统配置 | 联系开发负责人查询。 |
| Directus Editor | 运营维护新闻、图片和正文内容 | 联系开发负责人查询。 |
| Directus Token / Secret | 脚本、迁移或应急管理访问 | 联系开发负责人查询；使用后按需轮换。 |
| Directus Docker Compose 环境变量 | Directus 服务恢复、迁移、排障 | 联系开发负责人查询。 |

## 3. 在其他文档中的位置

- 阿里云、宝塔、Directus、CDN / DNS 的界面位置和运维说明见 [部署、服务器、宝塔、域名与 CDN](./deployment-server-cdn.md)。
- Directus 新闻运营账号的使用边界见 [Directus 新闻编辑器使用手册](../operations/directus-news-guide.md)。
- 正文中英文内容维护见 [正文中英文对照表配置](../operations/directus-i18n-guide.md)。

## 4. 禁止事项

- 不要把真实密码、Token、Secret、AccessKey、私钥写进仓库文档。
- 不要把凭据截图提交到仓库。
- 不要把 Directus Admin 账号作为日常运营账号共用。
- 人员变更、外包结束或疑似泄露时，联系开发负责人轮换相关凭据。
