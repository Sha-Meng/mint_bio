# 归档区说明

`doc/archive/` 用于保存历史资料。这里的内容**不代表当前有效流程**，正式操作请从 `doc/index.md` 进入。

## 目录说明

| 目录 | 存放内容 | 使用方式 |
|---|---|---|
| `update/` | 历史官网更新需求资料，例如旧版 PDF 更新方案 | 仅作需求背景和历史决策参考。 |
| `zh-en/` | 历史中英对照 docx | 可作为翻译来源之一，但使用前需确认是否覆盖当前页面和字段。 |
| `legacy-docs/` | 旧版架构、页面、新闻、CDN 文档 | 仅用于追溯旧实现，不能直接照旧操作。 |
| `i18n-runtime-migration_20260524.md` | 固定文案 Directus 运行时配置迁移记录 | 仅用于追溯建表、导入和验收过程。 |

## 使用原则

1. 归档资料中的路径、IP、接口、新闻维护方式可能已经过期。
2. 如果归档内容与 `operations/`、`ops-dev/` 冲突，以正式文档为准。
3. 英文翻译可以参考 `zh-en/`，但不得自行补译缺失内容。
4. 如需恢复归档中的某个流程，必须先核对当前代码、服务器配置和 Directus 状态。
