### 一、目标与范围

- **总体目标**：
  - 统一使用 **新阿里云账号** 承载本项目的云上资源（ECS、CDN、域名解析等），旧账号在迁移完成后废弃；
  - 使用阿里云 CDN / DCDN 对网站做 **全球加速（含中国内地 + 海外）**。
- **当前网站形态（现状）**：
  - 前端为 Vue 静态站（本仓库 `mint_bio` 构建产物）。
  - 网站运行在 **旧账号 A 的 ECS 公网服务器** 上，并通过该 ECS 对外服务。
  - 域名（如 `mint-bio.cn`、`www.mint-bio.cn`）的解析已统一由新账号 B 的云解析 DNS 管理，其中：
    - `www.mint-bio.cn`：CNAME 指向新账号 CDN 分配的 `www.mint-bio.cn.queniuaa.com`；
    - `mint-bio.cn`：CNAME 指向新账号 CDN 分配的 `mint-bio.cn.w.cdngslb.com`；
  - 新账号 B 的 CDN 已为 `www.mint-bio.cn` 与 `mint-bio.cn` 分别配置加速域名，源站暂指向旧 ECS 公网 IP `8.155.35.138`。
- **CDN 计费模式约定**：
  - 采用 **按量计费（后付费）**，暂不购买流量资源包，待有稳定访问量后再按需购买资源包优化成本。

### 三、阶段 1：在新账号接入 CDN 并完成双域名加速（已完成）

#### 1. 需求与策略确认

- 目标：
  - 在新账号 B 的 CDN / DCDN 控制台中，为 `www.mint-bio.cn` 与 `mint-bio.cn` 同时建立 **全球加速** 配置；
  - 源站继续回源旧账号 A 的 ECS 公网 IP `8.155.35.138`，业务无缝过渡；
  - 完成 CDN 层的 HTTPS 与缓存策略配置后，再分阶段迁移源站与域名解析到新账号。

#### 2. `www.mint-bio.cn` 加速接入与验证

- 已在新账号 B 中添加 `www.mint-bio.cn` 加速域名：
  - 加速区域：全球（含中国内地）；
  - 业务类型：图片小文件/静态网页；
  - 源站类型：IP，地址 `8.155.35.138`；
  - 回源协议：HTTP 80；
  - 回源 Host：短期配置为自定义值 `8.155.35.138`（匹配旧 ECS 上 Nginx `server_name`，保证回源命中正确站点）。
- DNS：
  - `www.mint-bio.cn` 在云解析 DNS 中配置为 CNAME：`www.mint-bio.cn.queniuaa.com`；
  - 外部查询：`nslookup www.mint-bio.cn 8.8.8.8` 返回 CDN 节点 IP，证明 CNAME 已生效。
- 浏览器验证：
  - 访问 `www.mint-bio.cn` 正常；
  - 静态资源（JS/CSS/图片）响应头中包含 `Via`、`X-Cache` 等 CDN 标记，且多次刷新后 `X-Cache` 由 MISS 逐步转为 HIT，说明缓存命中正常。

#### 3. `mint-bio.cn` 根域加速接入与验证

- 已在新账号 B 中新增 `mint-bio.cn` 加速域名：
  - 配置与 `www.mint-bio.cn` 类似，源站为旧 ECS IP，回源 Host 为 `8.155.35.138`；
- DNS：
  - `mint-bio.cn`（`@` 记录）在云解析 DNS 中配置为 CNAME：`mint-bio.cn.w.cdngslb.com`；
  - 外部查询：`nslookup mint-bio.cn 8.8.8.8` 返回 CDN 节点 IP `113.113.100.22`；
- 浏览器验证：
  - 访问 `mint-bio.cn` 正常，响应头中同样可见 CDN 标记；
  - 后续可在 Nginx 或 CDN 规则引擎中按需配置根域 301 跳转到 `www.mint-bio.cn`，实现 URL 统一（待选项）。

#### 4. CDN 缓存策略（当前配置）

- **静态资源（JS/CSS/图片/字体等）长缓存规则**：
  - 匹配类型：文件后缀名；
  - 后缀：`js,css,png,jpg,jpeg,gif,svg,ico,webp,ttf,woff,woff2`；
  - 缓存时间：1 个月；
  - 优先遵循源站缓存头：关闭；
  - 忽略源站不缓存标头：关闭；
  - 存缓存：开启；
  - 规则状态：成功。
- **HTML 页面短缓存规则**：
  - 匹配类型：文件后缀名；
  - 后缀：`html`；
  - 缓存时间：5 分钟；
  - 其他选项保持默认，用于兼顾更新及时性与少量缓存收益。
- 验证：
  - 静态资源请求的 `Cache-Control` / `max-age` 与规则一致；
  - 多次刷新后，CDN 节点对静态资源的 `X-Cache` 状态稳定为 HIT，说明规则生效。

### 七、历史问题与决策记录

- **Q1：在“边缘安全加速资源包”购买页面如何选择？是否必须购买？**  
  - 结论：该页面仅用于购买流量资源包，并非接入 CDN 的必经步骤。当前采用按量计费，暂不购买资源包。
- **Q2：要在新账号接入 `mint-bio.cn`，但提示“该域名已归属其他账号”，怎么办？**  
  - 结论：这是因为旧账号的 CDN 中仍存在该加速域名，即便已停用也会占用归属。处理方式：
    - 优先在旧账号 CDN 中删除相关加速域名；
    - 若无法删除，则在新账号中按提示进入“域名找回/迁移”工具，通过 DNS 或文件验证完成归属迁移。
- **Q3：`www.mint-bio.cn` 在云解析中自 2025-02-06 起被单独添加为子域名，导致主域名下的 `www` 记录不生效，如何修复？**  
  - 结论：需在旧账号 DNS 控制台删除 `www.mint-bio.cn` 子域 Zone，使 `www` 的 DNS 管理权回归主域 `mint-bio.cn`，然后在新账号云解析中统一为主域配置 `www` 记录；修复后，权威 NS 可正常返回 `www` 的 A/CNAME 记录，CDN CNAME 检测也恢复正常。
- **Q4：备案主体不变的情况下，跨账号更换 ECS、变更 IP 和接入 CDN 是否影响备案？**  
  - 结论：在主体不变、接入商仍为阿里云、服务器位于内地的前提下，上述调整不会导致备案失效，一般不需重新备案，仅建议迁移完成后更新备案中的接入信息。
